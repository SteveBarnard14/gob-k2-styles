# gob-k2-styles

Reusable style-profile assets for Nintex K2 SmartForms.

## Detail Slider

Use the `k2-slider-*` Data Label files to show an existing K2 item view in a right-side slider after a list row click. K2 rules remain responsible for selecting the row and populating the view.

Current files:

- `k2-slider-styles.datalabel.css`
- `k2-slider-library.datalabel.js`
- `k2-slider-on-list-row-click-open.datalabel.js`
- `k2-slider-after-view-populated-hide-loader.datalabel.js`
- `k2-slider-on-action-complete-close.datalabel.js`
- `k2-slider-notify-helper.datalabel.js`
- `assets/bahamas-coat-of-arms.png` optional loading-logo asset

See `docs/k2-slider-smartforms.md` for the current implementation pattern.
